# Ассеты

## Перед добавлением

1. **Лицензия.** Проверь по первоисточнику (не по памяти) и сверься с `docs/LICENSING.md`. Нет понятной лицензии — не добавляй.
2. Запиши в `CREDITS.md`: файл(ы), автор, источник (URL), лицензия, дата проверки.
3. Бинарные файлы (`.glb`, `.png`, `.ogg`, `.blend`) — через Git LFS (см. `.gitattributes`).

## Форматы

- 3D — GLB (glTF 2.0 Binary). Исходники `.blend` — в `art/` (не в модулях).
- Текстуры — PNG, сторона — степень двойки, ≤ 2048.
- Звук — OGG Vorbis.

## Экспорт из Blender

- Масштаб: 1 единица = 1 метр; клетка сетки = 1.5 м. Персонаж среднего роста ≈ 1.8 м.
- Перед экспортом: применить трансформации (Apply All Transforms), применить модификаторы, удалить неиспользуемые материалы.
- Персонажи: один скелет, гуманоидная иерархия костей с понятными именами (для `SkeletonProfileHumanoid`), ≤ 100 костей, ≤ 50k треугольников (цель для low-poly — 3–15k).
- Экспорт: glTF 2.0 Binary, +Y Up, включить скиннинг и анимации, только выделенные объекты.
- Имена: `snake_case`, без пробелов и кириллицы: `goblin_warrior.glb`, `anim_humanoid_walk.glb`.

## AI-генераторы

Модели от генераторов обычно плотные, с «запечённым» светом и плохим ригом. Для нашего стиля: ретопология → UV → перезапекание текстуры без освещения → риг (или авториг) → проверка в спайк-сцене. Без проверки лицензии конкретного сервиса и тарифа такие модели в репозиторий не попадают.

## Анимации и ретаргетинг

Анимации делаются один раз на эталонный гуманоидный скелет и ретаргетятся на модели через `SkeletonProfileHumanoid` / `BoneMap`. Mixamo-анимации нельзя распространять отдельными файлами в модулях (см. LICENSING).

## Загрузка во время игры

Только через валидатор (размер файла, треугольники, текстуры, кости) → `GLTFDocument.append_from_buffer()` / `append_from_file()` → `generate_scene()`. Ошибки — понятным сообщением, не падением.
