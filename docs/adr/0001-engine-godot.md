# ADR-0001: Движок Godot 4.x

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Desktop (Windows/Linux/macOS), 3D low/mid-poly, загрузка пользовательских моделей во время игры, собственный редактор приключений, бесплатность, код пишут AI-агенты.

## Решение

Godot 4.x. Точная версия закрепляется при создании проекта ([OPEN_QUESTIONS](../OPEN_QUESTIONS.md) №1) и меняется только отдельным PR с прогоном всех тестов, включая golden.

## Рассмотренные варианты

- **Godot 4** — MIT, без роялти; `GLTFDocument` грузит GLB со скелетом и анимациями во время игры; текстовые форматы удобны агентам; маленькие билды. Минусы: меньше готовых RPG-фреймворков и 3D-ассетов, графика слабее UE5 (для low-poly неважно).
- **Unity 6** — C#, Asset Store; но runtime-загрузка моделей через сторонние пакеты, сохранение сцен в рантайме — самому, лицензия менялась, Personal до $200k.
- **Unreal 5** — лучшая графика и GAS, но бинарные `.uasset`, тяжёлые итерации, роялти 5% после $1M, оверкилл для low-poly.

## Последствия

- Web/мобильные теоретически доступны, но не поддерживаются и не тестируются.
- Подпись macOS-билдов требует macOS-окружения в CI.
