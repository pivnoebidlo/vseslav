# ADR-0003: Модуль = JSON + ассеты, без сохранения `.tscn`

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Весь контент — модули; модулями обмениваются игроки; редактор должен работать и в экспортированной игре. Сохранение `PackedScene` во время игры требует корректных `owner`, путей ресурсов и тянет за собой произвольные ресурсы Godot (в т. ч. скрипты).

## Решение

- Авторитетные данные модуля — JSON-файлы по структуре из [SPEC §7](../SPEC.md#7-формат-модуля) + ассеты в поддерживаемых форматах.
- Сцены Godot строятся из данных при загрузке и **никогда** не являются форматом модуля; `.tscn`/`.tres`/`.res` в модулях запрещены.
- Ссылки — только по id; пути ассетов — относительные внутри модуля.
- Каждому типу файла соответствует JSON Schema в `schemas/`; валидация при загрузке и сохранении.

## Последствия

- Модули переносимы между ОС, диффабельны, их легко генерировать агентам.
- Нужно писать загрузчик/построитель сцен и сериализацию модели — это осознанная цена.
- Модуль не может протащить в игру скрипт GDScript через ресурс.
