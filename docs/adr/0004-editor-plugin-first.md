# ADR-0004: Редактор — сначала плагин Godot, потом встроенный

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Нужен редактор приключений в духе NWN2 Toolset, в итоге — встроенный в игру. Полноценный встроенный редактор — продукт размером с игру; на старте он блокировал бы создание контента.

## Решение

1. **Этап A:** `EditorPlugin` в `addons/vseslav_editor/` для команды; редактирует JSON-модель модуля.
2. **Этап B:** встроенный в игру редактор на `Control`-нодах для игроков.
3. Всё, что нужно обоим (модель, команды, undo/redo, валидация, упаковка), живёт в `editor/` и `core/` и **не использует** API редактора Godot. В `addons/vseslav_editor/` — только UI-обвязка плагина.

## Рассмотренные варианты

- Сразу встроенный — один продукт, но редактор на критическом пути с первых месяцев.
- Отдельная тулза-приложение — два продукта, без выигрыша.

## Последствия

- `EditorInterface`, `EditorPlugin`, `EditorUndoRedoManager`, импорт ресурсов недоступны в экспортированной игре — код с ними не должен попадать в `editor/` и `core/`.
