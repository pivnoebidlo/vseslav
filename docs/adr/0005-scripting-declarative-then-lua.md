# ADR-0005: Скрипты — декларативные события, Lua 5.4 позже

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Нужна настраиваемость уровня NWScript. Модули — недоверенные данные. Песочница для GDScript отсутствует. Lua-песочница — отдельный объём работы и бинарные зависимости под все платформы.

## Решение

- До этапа 6 — **декларативные события** `on → if → then` с закрытым списком триггеров, условий и действий ([SPEC §8](../SPEC.md#8-скрипты-модулей)).
- На этапе 6 — **Lua 5.4** через готовый GDExtension-биндинг, с требованиями из SPEC §8. Lua API работает поверх тех же команд ядра, что и события.
- **Запрещено:** исполнять GDScript из модулей (`GDScript.new()`, `load()` скриптов из `user://`), использовать `Expression` для данных модулей, LuaJIT.

## Рассмотренные варианты

- GDScript из строки — нет песочницы.
- Lua сразу — песочница на критическом пути до первого играбельного боя.
- AngelScript, QuickJS, WASM — меньше экосистема/сложнее биндинг; пересмотреть только если Lua не подойдёт.
- LuaJIT — debug hook не работает в JIT-коде, нет кастомного аллокатора на x64, JIT на macOS требует отдельных entitlements; скорость пошаговой игре не нужна.

## Последствия

- `api_version` в манифесте версионирует набор событий уже сейчас.
- Добавление нового действия события = изменение кода игры + схема + документация + тест.
