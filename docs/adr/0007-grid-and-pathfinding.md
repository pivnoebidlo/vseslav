# ADR-0007: Квадратная сетка и собственный A*

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Бой пошаговый на сетке с уровнями высоты, укрытиями и зонами эффектов; детерминизм обязателен.

## Решение

- Квадратная клетка 5 футов = 1.5 м (единиц Godot). Координаты клетки — `Vector3i(x, level, z)`.
- Логическая сетка в `core/grid/`, отдельно от визуала.
- Поиск пути — собственный A* в ядре; равенство приоритетов разрешается детерминированно (по `f`, затем `h`, затем по координатам).
- Стоимость диагонали — параметр ruleset (`chebyshev` / `alternating`), по умолчанию — [OPEN_QUESTIONS](../OPEN_QUESTIONS.md) №3.
- Линия видимости и укрытие — по клеткам (трассировка Брезенхема/супер-покрытие в 3D с учётом уровней и блокирующих граней клеток); физические лучи Godot в правилах не используются.
- Зоны эффектов растрируются на клетки по правилам ruleset.

## Рассмотренные варианты

- `AStarGrid2D` — нет уровней высоты.
- `AStar3D` — граф общего вида, порядок обхода при равенствах не гарантирован, держать в синхроне с картой неудобно.

## Последствия

- Нужны тесты: путь, стоимость, LoS, укрытие, растризация зон — на маленьких картах-фикстурах.
