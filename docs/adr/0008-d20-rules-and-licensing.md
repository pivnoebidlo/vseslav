# ADR-0008: Ядро d20 в коде, контент в данных, SRD под CC-BY

- Статус: Принято
- Дата: 2026-11-18

## Контекст

RPG на переработанной системе d20. Команда маленькая; «сменный набор правил как total conversion» резко усложняет сохранения и API.

## Решение

- Механики (броски, модификаторы, проверки, атаки, урон, состояния, экономика действий, инициатива, отдых) — код в `core/rules/` и `core/combat/`.
- Контент (классы, расы, черты, заклинания, предметы, существа) — данные ruleset/модуля.
- Формулы в данных — собственный парсер выражений (кости `NdM`, `+ - * /` с целочисленным делением вниз, `min/max`, переменные из белого списка).
- Основа — SRD 5.2/5.1 под CC-BY-4.0 ([LICENSING](../LICENSING.md)); наши изменения описываются в `docs/rules/`.
- Полная замена правил модулем — не цель; формат её не запрещает.

## Последствия

- Изменение механики = изменение кода + `docs/rules/` + тесты.
- Изменение баланса/контента = изменение данных, без кода.
