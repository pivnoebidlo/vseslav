# ADR-0009: GLB как канонический формат ассетов

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Модели от AI-генераторов, из Blender и от пользователей; загрузка во время игры; low-poly стиль.

## Решение

- 3D — glTF 2.0 / GLB; текстуры — PNG; звук — OGG.
- Во время игры модели грузятся через `GLTFDocument`; импорт `.blend`/FBX — только в редакторе команды.
- Анимации — на `SkeletonProfileHumanoid` с ретаргетингом.
- Для прототипов — CC0-паки (Quaternius, KayKit, Kenney). AI-модели — после проверки лицензии и ретопологии под low-poly.
- Лимиты пользовательских моделей — [SPEC §11](../SPEC.md#11-ассеты-и-модели).
- Бинарные ассеты — Git LFS.

## Последствия

- Нужен валидатор GLB (размер, треугольники, текстуры, кости) до передачи в `GLTFDocument`.
