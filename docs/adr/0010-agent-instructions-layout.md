# ADR-0010: AGENTS.md и общие скилы для всех агентов

- Статус: Принято
- Дата: 2026-11-18

## Контекст

Команда использует Claude Code, opencode, Codex, Cursor и другие агенты. Инструкции не должны расходиться между инструментами.

## Решение

- Единственный источник инструкций — `AGENTS.md` в корне. `CLAUDE.md` только импортирует его (`@AGENTS.md`).
- Скилы — в `.agents/skills/<name>/SKILL.md` (формат Agent Skills: YAML-фронтматтер `name`, `description`). `.claude/skills` — симлинк на `.agents/skills`.
- `AGENTS.md` перечисляет скилы, чтобы агенты без поддержки скилов могли прочитать нужный файл вручную.
- Изменения в инструкциях проходят ревью как код.

## Последствия

- В Windows симлинки требуют `git config core.symlinks true` и режима разработчика; иначе Claude Code-пользователям на Windows — читать скилы по путям из `AGENTS.md`.
