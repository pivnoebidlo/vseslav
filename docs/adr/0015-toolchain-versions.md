# ADR-0015: Версии инструментов

- Статус: Принято
- Дата: 2026-11-19
- Закрывает открытый вопрос №1

## Решение

| Инструмент | Версия | Где закреплено |
|---|---|---|
| Godot | **4.7.2 stable** | `project.godot` (`config/features` = 4.7), шаблоны экспорта той же версии |
| GUT | **9.7.1** | `addons/gut/plugin.cfg` |
| gdtoolkit | **4.5.x** | `README.md` (установка) |

- Обновление любой версии — отдельный PR: прогон `tools/test.sh` (включая golden-реплеи), `tools/lint.sh` и сборки `tools/export.sh`.
- Если обновление Godot меняет результат golden-реплея — это изменение `RandomNumberGenerator`; см. [ADR-0006](0006-determinism-and-rng.md).

## Последствия

- Все в команде и в CI используют одну и ту же версию Godot; иная версия может изменить `.import` и `.uid` файлы и дать шумные диффы.
