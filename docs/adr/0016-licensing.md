# ADR-0016: Лицензии проекта

- Статус: Принято
- Дата: 2026-11-19

## Контекст

Репозиторий публичный. Без лицензии код и контент по умолчанию «все права защищены», и участвовать в проекте юридически нельзя.

## Решение

- **Код — MIT** (`LICENSE`).
- **Контент — CC BY-SA 4.0** (`LICENSES/CC-BY-SA-4.0.txt`): модули, локализация, арт, документация, тексты, модели, звук.
- Точное разделение по путям и правило для неоднозначных файлов — `LICENSES/README.md`.
- Правообладатель — «Vseslav contributors».

## Рассмотренные варианты

- GPL-3.0 для кода — обязывает открывать производные проекты; команда предпочла свободную MIT.
- «Все права защищены» для контента — закрывает мир от сообщества и модулей; противоречит идее обмена модулями.

## Последствия

- Сторонний контент под CC BY 4.0 (SRD) и CC0 (Quaternius, KayKit, Kenney) совместим с CC BY-SA.
- Нельзя добавлять контент под лицензиями, несовместимыми с CC BY-SA (например, CC BY-NC, CC BY-ND, «только для личного использования»), — `docs/LICENSING.md`.
- Пользовательские модули, производные от нашего контента, распространяются под CC BY-SA; собственные модули с нуля авторы лицензируют сами.
