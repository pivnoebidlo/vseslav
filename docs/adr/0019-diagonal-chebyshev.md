# ADR-0019: Диагональ по умолчанию — Чебышёв

- Статус: Принято
- Дата: 2026-11-19
- Участники: команда (решение пользователя в сессии с агентом)
- Закрывает открытый вопрос №3

## Контекст

[ADR-0007](0007-grid-and-pathfinding.md) сделал стоимость диагонали параметром (`chebyshev` или `alternating`), но значение по умолчанию оставил открытым.

## Решение

- По умолчанию `diagonal = "chebyshev"`: шаг по диагонали стоит 1 клетку (5 футов), как в SRD 5.2.
- Вариант `alternating` (5-10-5) остаётся в коде и доступен через ruleset/арену, но базовая кампания его не использует.
- Дальность (оружие, заклинания, области) тоже считается по Чебышёву: квадрат вокруг клетки, а не круг.

## Рассмотренные варианты

- Чебышёв — проще предсказывать игроку и показывать в UI; совпадает с SRD 5.2. Минус: диагональ «короче», чем в реальной геометрии.
- 5-10-5 — точнее, но игроку труднее считать в уме.

## Последствия

- Golden-реплеи и тесты пишутся с `chebyshev`; `alternating` покрывается отдельными тестами поиска пути.
