# ADR-0033: Модели окружения — наборы CC0 на символах карты и явные объекты

- Статус: Принято
- Дата: 2026-11-22
- Участники: команда (решения пользователя в сессии с агентом)
- Уточняет [ADR-0029](0029-exploration-sketch.md) (облик области); связано с [ADR-0009](0009-assets-pipeline.md), [ADR-0016](0016-licensing.md)

## Контекст

Карта рисовалась коробками и конусами. Хотелось реализма. Рассматривали Dungeon Alchemist: он не умеет выгружать 3D (только картинку сверху и стены/свет для VTT, разработчики 3D-экспорт не планируют), а его условия использования не говорят прямо о видеоиграх и запрещают раздавать части программы. Значит, нужны свои 3D-модели с понятной лицензией.

## Решение

- **Модели — наборы CC0 в стиле наших фигур**: KayKit Medieval Hexagon и Halloween Bits (Kay Lousberg). Нужные `.gltf` переводятся в `.glb` (`tools/import_kaykit_props.sh`, `tools/convert_gltf.gd`) и лежат в базовом модуле `modules/base/props/` (импорт Godot — `keep`, грузятся через `CharacterLoader`, как фигуры, ADR-0022). Записаны в `CREDITS.md`.
- **Набор моделей** — `props/props.json` (схема `props.schema.json`): id → файл, `fit` (во сколько раз модель может выйти за свои клетки — кроны деревьев шире клетки), `jitter` (разброс размера), `spin` (случайный поворот: нет, на четверть, любой).
- **Стиль области** — `style` в `areas/<id>.json`: какими моделями рисовать символы карты: `tree` (T), `house` / `house_large` / `well` (связная группа # по числу клеток), `fence` (=, вдоль соседей), `grave` (+), `yard` (мелочи на клетках постройки, не занятых домом), `scatter` (камешки на земле). Выбор из списка и поворот — по клетке, одинаково при каждом запуске.
- **Явные объекты** — `objects`: модель в прямоугольнике клеток с поворотом (кузница, изба старосты, склеп, палатки разбойников). Их клетки стилем не рисуются.
- **Проходимость по-прежнему задаёт символьная карта**: модели — только облик. Модель вписывается в свои клетки (с учётом `fit`).
- **Отрисовка**: каждая модель грузится один раз и размножается через `MultiMesh` (сотни деревьев — одна отрисовка на меш). Без стиля — прежняя простая геометрия.
- **Арена убрана из главного меню**: бой идёт на карте (ADR-0032). Арена остаётся инструментом разработчика (баланс, golden-реплеи, дымовые проверки) и открывается запуском с `--arena`. Снаряжение, торг и отдых — кнопками на карте.

## Рассмотренные варианты

- **Импорт карт Dungeon Alchemist (`.dd2vtt`)**: картинка на земле и стены из файла — плоско в 3D-игре, лицензия для игр неясна. Отклонено.
- **Модели Quaternius / Kenney** — тоже CC0, но другой стиль; KayKit совпадает с фигурами героев.
- **Сразу расставлять всё объектами** — без редактора долго; символы со стилем дают картинку сразу, объекты — точность там, где нужно.

## Последствия

- Новый тип модели окружения = файл в `props/` + строка в `props.json` (+ CREDITS.md); схемы и проверка ссылок ловят неизвестные id и пропавшие файлы.
- Модели KayKit фэнтезийные и яркие; облик эпохи (избы-срубы, частоколы) — свои модели на этапе 4.
- Расстановку объектов удобно делать в редакторе (этап 3).
