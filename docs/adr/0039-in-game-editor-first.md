# ADR-0039: Редактор сюжета — сначала встроенный в игру, начиная с диалогов и квестов

- Статус: Принято
- Дата: 2026-11-22
- Участники: команда (решения пользователя в сессии с агентом)
- Меняет порядок этапов [ADR-0004](0004-editor-plugin-first.md); связано с [ADR-0028](0028-module-loader-and-schemas.md), [ADR-0029](0029-exploration-sketch.md), [ADR-0034](0034-areas-exits-quests.md)

## Контекст

Команде нужно писать свой сюжет — диалоги, квесты, флаги — без ручной правки JSON. По ADR-0004 первым шёл плагин к редактору Godot, но не все авторы сюжета ставят Godot и работают с репозиторием, а тестерам и так неудобно запускать игру из консоли.

## Решение

- **Редактор встроен в игру** (пункт «Редактор» в главном меню) и строится на `Control`-нодах. Принцип ADR-0004 сохраняется: вся логика — в `editor/` без API редактора Godot (`ModuleDoc` — модель модуля, `DocEdit` и `UndoStack` — правки с отменой, `DialogOps`, `QuestOps` — операции, `ModuleWorkspace` — список модулей). Плагин Godot, если понадобится, ляжет на ту же логику.
- **Первая часть — диалоги и квесты**: граф реплик и ответов, тексты на русском и английском, условия по флагам, проверки характеристик, действия (`set_flag`, `set_quest`), стадии квестов; проверка модуля загрузчиком игры; «Сыграть». Карты областей и расстановка — следующими частями.
- **Где сохраняется**: модули игры (`res://modules`) правятся, только когда игра запущена из исходников (`godot --path .`) — правки сразу в репозитории, их можно закоммитить. В собранной игре — свои модули в `user://modules` (создаются в редакторе, зависят от базового); чтобы поправить чужой диалог, его копируют в свой модуль — запись с тем же id заменяет исходную (ADR-0028).
- **Ключи строк создаются сами**: `DLG_<ДИАЛОГ>_<РЕПЛИКА>`, `DLG_<ДИАЛОГ>_<РЕПЛИКА>_O<n>` для ответов, `QUEST_<ID>`, `QUEST_<ID>_<СТАДИЯ>`; название модуля — `MODULE_<ID>`. Автор видит и правит только текст.
- **Метаданные редактора** (положения реплик в графе) — в поле `_editor` файла диалога; игра его не читает.
- Файлы пишутся JSON с отступом в 2 пробела, порядок ключей сохраняется, целые числа — без `.0`.

## Рассмотренные варианты

- **Плагин Godot первым** (ADR-0004) — удобно тем, кто в Godot, но отсекает остальных авторов. Отложено.
- **Внешний веб-редактор** — ещё одна кодовая база и формат; не проверяет модуль загрузчиком игры. Отклонено.
- **Таблицы вместо графа** — проще, но ветвящийся диалог в таблице читать трудно.

## Последствия

- ROADMAP: работа этапа 5 (встроенный редактор) начинается раньше этапа 3; этап 3 (плагин) — по необходимости.
- Редактор показывает ошибки загрузчика по своему модулю — те же, что увидит игра.
- Жители областей (имя, клетка, облик, диалог) — сразу следом; область чужого модуля копируется в свой (`NpcOps.copy_area`), файл области после сохранения совпадает с исходным.
- Следом: карты областей.
