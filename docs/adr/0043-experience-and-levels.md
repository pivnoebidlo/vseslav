# ADR-0043: Опыт и уровни, окно «Герой»

- Статус: Принято
- Дата: 2026-11-23
- Участники: команда (решения пользователя в сессии с агентом)
- Развивает SPEC §3 (прогрессия — данные ruleset); связано с [ADR-0027](0027-rest.md), [ADR-0035](0035-hud-and-settings.md), [ADR-0038](0038-party-of-six.md), [ADR-0042](0042-events-v1.md)

## Контекст

Герои стояли на уровне из данных персонажа (3), опыта не было, а лист персонажа существовал только как макет окна «Герой». SPEC требует прогрессию в данных правил, а среди начальных действий событий — выдачу опыта.

## Решение

- **Таблица опыта — в данных правил**: `rules/classes.json` → `xp_levels`, опыт всего для уровней 1, 2, 3… (первый — 0, дальше по возрастанию, не больше 20 уровней). В базовом модуле — таблица SRD 5.2. Модуль-дополнение заменяет таблицу целиком. Без таблицы уровни не растут.
- **Опыт и уровень хранит каждый герой** в состоянии партии (`HeroState.level`, `HeroState.xp`; сохраняются вместе с ранами). Уровень из данных персонажа — начальный; новый герой и старое сохранение получают опыт, ровно положенный этому уровню.
- **Опыт получает каждый в отряде полностью** (как в компьютерных RPG, не делится на число героев); кто не в отряде — не получает.
- **Источники опыта**: действие событий `give_xp {amount}` (диалоги, победы, сундуки, события области) и победа в бою — сумма `xp` существ противника из `rules/creatures.json` (в базовом модуле — по SRD для их сложности).
- **Уровень не растёт сам**: когда опыта хватает, на вкладке героя появляется ▲, а в окне «Герой» загорается «Повысить уровень» — по одному уровню за раз. Кнопка заранее показывает, что даст уровень: хиты (среднее кости хитов + Тел, как и раньше в сборщике бойца), новые умения класса и пути, рост мастерства. Хиты и кость хитов добавляются сразу, раны остаются ранами.
- **Окно «Герой» (клавиша C)** — по макету: вкладки героев (Tab), портрет, класс, путь, уровень, происхождение, полоска опыта, характеристики (главная выделена), спасброски с владением, боевые числа (КД, хиты, скорость, инициатива, мастерство, кости хитов), умения класса и пути с цветом цены, заговоры. Только вне боя.

## Не сейчас

- Выборы при повышении (увеличение характеристик или черта на 4-м уровне, новые заговоры): уровни 4+ дают пока только хиты и мастерство — содержимое классов выше 3-го уровня ещё не написано.
- Навыки и блок спутника из макета (отношение, история, личный квест) — вместе с навыками в правилах и отношениями спутников.
- Начальный опыт и уровень в `start` модуля.

## Последствия

- Сохранения старого формата читаются: уровень и опыт берутся из данных персонажа.
- Сборка героя для боя, экранов и отдыха идёт через `Party.character_data` — с текущим уровнем.
- Редактор: действие «опыт» в списке действий событий и ответов.
