# ADR-0050: Торг только с купцами

- Статус: Принято
- Дата: 2026-11-26
- Участники: команда (решение пользователя в сессии с агентом)
- Развивает [ADR-0025](0025-trade.md), [ADR-0049](0049-trade-at-merchant.md)

## Контекст

Спор о модели торговли: «как в Fallout 2» — менять вещи можно с любым встречным, даже не торговцем; или «как в BG/NWN/PoE» — торговля только с назначенными купцами. На момент решения экран торга уже открывался у купца (ADR-0049), но вкладки позволяли переключиться на любого купца, а «торговость» жителя была неявной — совпадением id с записью в `merchants.json`.

## Решение

- **Торгуют только купцы** (модель BG/NWN/PoE): у жителя области явное поле `"merchant": true`; в разговоре с ним появляется кнопка «Торг» (ADR-0049). У жителей без поля кнопки нет, и торговать с ними нельзя.
- **Запись купца** (`merchants.json`) с тем же id обязательна: у неё наценка, доля выкупа, запас и кошелёк (ADR-0025). Житель-«торговец» без записи — ошибка загрузчика: `unknown merchant '<id>'`; модуль не грузится.
- **Вкладки купцов в экране торга убраны**: торгуем только с тем, к кому подошли. Вкладка выбора героя-торговца остаётся.
- **Редактор**: у жителя чекбокс «Торговец».
- Отдельного поля «купец» у жителей нет и не появится: торговец без товара и кошелька — не торговец, дублировать связь двумя флагами не нужно.

## Рассмотренные варианты

- **Barter со всеми (Fallout 2)** — отклонено: ломает достоверность быта (торговля — социальная роль, а не всеобщий навык), требует экономики (запас, кошелёк) для каждого жителя или затычек, выхолащивает наценки ADR-0025. Обмен внутри отряда уже есть («передать»), а отдать/получить вещь или деньги от жителя можно действиями диалогов (`give_item`, `take_item`, `give_money`) — этого для откупа, даров и взяток достаточно.
- **Неявная связь по id без поля** (как было) — отклонено: случайное совпадение id жителя с купцом молча включает торговлю, а намерение автора не видно в файле области.
- **Купец без помеченного жителя — ошибка загрузчика** — не принято: мёртвая запись безвредна (экран до неё не открыть), а строгая проверка мешала бы модулю-«датапаку», который объявляет купцов для областей зависимых модулей.

## Последствия

- Модули с купцами обязаны помечать жителей: в spike-модуле помечены кузнец и травница.
- Переключаться между купцами, не подходя к ним, больше нельзя — «дорога к купцу» стала частью игры.
- SPEC §3.4 и §7 обновлены вместе с этим ADR.
