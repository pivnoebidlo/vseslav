# Architecture Decision Records

Каждое значимое решение — отдельный файл `NNNN-kebab-name.md` по [шаблону](0000-template.md). Как писать — скил `record-decision`.

Статусы: `Предложено` → `Принято` → (`Заменено ADR-XXXX` | `Отменено`). Принятые ADR не переписываются задним числом: чтобы изменить решение, пишется новый ADR, а старый получает статус «Заменено».
