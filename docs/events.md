# События модулей: справочник (v1)

Декларативные события ([SPEC §8](SPEC.md#8-скрипты-модулей), [ADR-0034](adr/0034-areas-exits-quests.md), [ADR-0042](adr/0042-events-v1.md)). Один язык действий — в ответах и репликах диалогов (`then`), победе в бою (`then` у энкаунтера), первом открытии сундука и событиях области. Условия — флаги.

## Условия (`if`)

`{"flag": "имя", "eq": значение}` — флаг равен значению; незаданный флаг — `false`. Все условия списка должны выполняться.

Флаги, которые ставит игра:

| Флаг | Значение |
|---|---|
| `quest.<id>` | стадия квеста (строка) или `false` — не начат |
| `party.<персонаж>` | `true` — в отряде, `false` — отпущен |
| `won.<энкаунтер>` | бой выигран |
| `event.<область>.<событие>` | однократное событие уже было |

## Действия (`then`)

| Действие | Поля | Что делает |
|---|---|---|
| `set_flag` | `flag`, `value` (по умолчанию `true`) | ставит флаг |
| `set_quest` | `quest`, `stage` | стадия квеста; журнал отметит изменение |
| `give_item` | `item`, `count` (1) | вещь в мешок герою, который говорит (или выбран) |
| `take_item` | `item`, `count` (1) | забирает у отряда, сколько найдётся |
| `give_money` | `kuny` (меньше нуля — забрать) | деньги в кошелёк героя / из кошельков отряда |
| `join_party` | `character` | принять в отряд (до 6); житель с условием `party.<id> = false` уходит с карты |
| `leave_party` | `character` | отпустить (последнего не отпустить) |
| `message` | `text` (ключ строки) | сообщение игроку |
| `start_dialog` | `dialog`, `speaker` (ключ имени, необязательно) | разговор после текущего |
| `start_combat` | `encounter` (id боя в текущей области) | начать бой |
| `teleport` | `area`, `spawn` | перенести отряд в область к точке появления |

Порядок: флаги, квесты, вещи и состав меняются сразу; сообщения, диалог, бой и перенос исполняются после — по порядку записи (диалог — когда закроется текущий).

## События области (`events` в `areas/*.json`)

```json
{ "id": "zasada", "on": "enter_zone", "zone": [10, 4, 6, 6],
  "if": [ { "flag": "quest.krysy", "eq": "started" } ],
  "then": [ { "action": "message", "text": "MSG_RUSTLE" }, { "action": "start_combat", "encounter": "volki" } ] }
```

- `on`: `enter_area` — при входе в область (после загрузки), `enter_zone` — когда ведущий отряда входит в прямоугольник `zone` `[x, z, ширина, глубина]`.
- `once` (по умолчанию `true`) — один раз за игру.

## Жители по условию

У жителя (`npcs`) поле `if` — когда он на месте. Будущий спутник: `"if": [{"flag": "party.tat", "eq": false}]` — стоит, пока не принят; после `join_party` исчезает с карты и встаёт в отряд.

## Начальный отряд

`module.json` → `start.party`: id персонажей в отряде с новой игры (до 6). Без поля — все персонажи модулей.
