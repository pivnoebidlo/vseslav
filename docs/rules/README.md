# Наши правила d20

Основа — SRD 5.2 (CC-BY-4.0, [ADR-0018](../adr/0018-srd-5-2.md)). Здесь описываются **только отличия и уточнения**: по одному файлу на подсистему (`combat.md`, `conditions.md`, `movement.md`, `magic.md`, `progression.md`, ...).

Формат файла: правило → как в SRD → как у нас → зачем. Код в `core/rules/` и `core/combat/` должен соответствовать этим файлам; при расхождении источник истины — этот документ (см. скил `d20-rules`).

Чего здесь нет — берётся из SRD 5.2 как есть.
