# Действия, черты и персонажи в данных

Данные — `modules/<id>/rules/*.json`, загрузка — `RulesDb`, сборка — `CombatantBuilder`, исполнение — `ActionResolver`.

## Действие (`actions.json`, оружие, приёмы существ)

| Поле | Значения |
|---|---|
| `cost` | `action`, `bonus`, `reaction`, `free` |
| `kind` | `attack`, `save`, `heal`, `effect`, `multiattack` |
| `attack_type` | `melee`, `ranged` |
| `ability` | `str`, `dex`, `spell` — что подставляется в `MOD` |
| `attack_bonus`, `save_dc`, `heal`, `damage[].formula` | формулы (`checks.md`); по умолчанию `MOD + PROF` и `8 + PROF + MOD` |
| `range`, `long_range` | клетки; ближний бой с `range` 1 — соседняя клетка с перепадом ≤ 1 |
| `target` | `enemy`, `ally` (включая себя), `self`, `point` |
| `area`, `area_size` | `burst` (квадрат радиуса вокруг точки), `cone` (от себя к точке); задевает **всех**, включая союзников |
| `tags` | метки урона: `silver`, `aspen`, `iron`, `wood`, `fire`, `spell`, `magic`, `weapon` |
| `save_ability`, `save_half` | спасбросок цели; половина урона при успехе |
| `effects[]` | `condition`, `on` (`hit`/`failed_save`/`always`), `rounds`, `save_ends`, `save_ability` (спасбросок против наложения при попадании) |
| `resource`, `resource_cost` | заряды умений, предметы (`item_<id>`); у заклинаний ячейку задаёт `spell_level` |
| `spell_level` | круг заклинания ([ADR-0044](../adr/0044-classes-to-level-5.md)): тратит ячейку `slot_<круг>`; если их нет — ближайшую выше, и действие усиливается на `upcast` за каждый круг сверху. Игрок может выбрать ячейку сам — строка «Ячейка» в панели хода у выбранного заклинания (`slot` в команде) |
| `upcast` | кости `NdM` к урону (тип — как у первой части урона) или к лечению за каждый круг ячейки выше круга заклинания |
| `lasting` | длящаяся зона ([ADR-0046](../adr/0046-lasting-spell-zones.md)): область остаётся, пока держится концентрация; срабатывает на входящих и заканчивающих в ней ход, раз за ход |
| `zone_of` | действие для сотворённого заклинания: передвинуть его зону или ударить снова, без ячейки, пока заклинатель на нём сосредоточен |
| `at_level` | урон заговора с уровня персонажа: `{"5": {"damage": [...]}}` — берётся наибольший достигнутый |
| `area` у лечения | лечение по области: союзники в ней, не больше шести, один бросок на всех |
| `concentration` | наложенные состояния снимаются при потере концентрации |
| `mastery` | приём оружия SRD 5.2; работают `graze`, `sap`, `topple`, `vex`, остальные пока без эффекта |
| `special` | `dash`, `disengage`, `dodge`, `extra_action`, `stand` |
| `sub_actions` | для `multiattack`: атаки по очереди по той же цели |

Урон области бросается один раз для всех целей.

## Черты (закрытый список, механика в коде)

`pack_tactics`, `bonus_damage` (`when`: всегда / `target_wounded` / `target_marked`, `once_per_turn`), `attack_bonus`, `ac_bonus` (`armored` — при сборке, `adjacent_ally` — строй), `improved_critical`, `protection` (реакция со щитом: помеха на атаку по соседнему союзнику; персонажа игрока бой спрашивает — ADR-0023), `revive` (встаёт, если последний урон не имел меток из `tags`), `aura`, `initiative`, `hp_per_level`.

## Персонаж = класс + путь + происхождение + инвентарь ([items.md](items.md))

- Характеристики: базовые + бонус происхождения (+2/+1 или +1/+1/+1 только из списка происхождения).
- Хиты: кость хитов + Тел на 1 уровне, далее (кость/2 + 1 + Тел) за уровень, плюс черты.
- КД: без доспеха 10 + Лов; лёгкий — база + Лов; средний — база + Лов (до +2); тяжёлый — база; щит +2; стиль «Оборона» +1 в доспехе. Тяжёлый доспех без нужной Силы — скорость −2 клетки.
- Оружие в руках и на поясе становится атакой: ближнее и метательное — Сила, дальнобойное — Ловкость, фехтовальное — лучшая из двух. Метательное расходует предметы. Мешок в бою недоступен.
- Приёмы оружия: класс с `weapon_mastery` владеет приёмами всего своего оружия (в SRD — выбор N видов; упрощение до редактора персонажа).
- Заклинания — из `spell_list` класса; путь может давать заклинания всегда.
- Умения класса и пути — по таблице уровней (`levels`), ресурсы берутся с последнего уровня, где заданы.

## Толкнуть и высота ([ADR-0037](../adr/0037-heights.md))

| Правило | Как в SRD | Как у нас | Зачем |
|---|---|---|---|
| Толкнуть | Часть безоружного удара: вместо урона цель (не больше чем на размер крупнее) спасается Силой или Ловкостью от СЛ 8 + Сила + мастерство; провал — отталкиваете на 5 футов или сбиваете с ног | Отдельное действие «Толкнуть» у всех (тратит действие). Цель выбирает лучший спасбросок. Выбор — двумя действиями: «Толкнуть» (провал — отлетает на клетку прямо от толкающего; если та клетка занята, непроходима или выше — сбита с ног; с уступа от 10 футов — падает: урон, сбит с ног) и «Сбить с ног». Вынужденное перемещение не провоцирует атак при отходе. Размер пока не учитывается | Сбросить врага с обрыва — главная тактика высоты; две кнопки проще окна выбора |
| ИИ и высота | — | ИИ толкает, только если цель полетит с уступа и шанс провала × (средний урон падения + 2) больше пользы удара; клетку для атаки выбирает повыше; прыгает с уступа, только если иначе никого не достать. «Сбить с ног» ИИ пока не использует | Противники пользуются той же тактикой, что игрок |
| Бонус за высоту | Нет | Домашнее правило: атакующий выше цели — +2 к броску атаки, ниже — −2 (ближний бой и дальний). Сравниваются уровни клеток | Как в BG3: высоту хочется занимать |
