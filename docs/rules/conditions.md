# Состояния и урон

Основа — SRD 5.2. Механика состояний — код (`core/rules/conditions.gd`), данные ссылаются на id.

## Состояния этапа 1

| id | Название | Как у нас | Отличие от SRD 5.2 |
|---|---|---|---|
| `blinded` | Ослеплён | Свои атаки с помехой, атаки по нему с преимуществом | Проверки, требующие зрения, пока не моделируются |
| `frightened` | Испуган | Помеха на атаки и проверки; нельзя добровольно приближаться к источнику | Линии видимости пока нет: источник считается видимым всегда |
| `incapacitated` | Недееспособен | Нет действий, бонусных действий и реакций; концентрация прерывается | — |
| `poisoned` | Отравлен | Помеха на атаки и проверки | — |
| `prone` | Сбит с ног | Свои атаки с помехой; атаки по нему с соседней клетки — с преимуществом, издалека — с помехой; встать стоит половину скорости | Ползком не перемещаемся: сначала встать |
| `restrained` | Опутан | Скорость 0; свои атаки с помехой; атаки по нему с преимуществом; помеха на спасброски Ловкости | — |
| `stunned` | Оглушён | Недееспособен; скорость 0; авт. провал спасбросков Силы и Ловкости; атаки по нему с преимуществом | Скорость 0 задаём явно |
| `unconscious` | Без сознания | Недееспособен и сбит с ног; скорость 0; авт. провал спасбросков Силы и Ловкости; атаки по нему с преимуществом, попадание с соседней клетки — критическое | Без «роняет предметы»: инвентаря в бою пока нет |

Служебные: `dodging` (действие «Уклонение»: атаки по нему с помехой и преимущество на спасброски Ловкости до начала его хода; пропадает при недееспособности), `marked` (метка ловчего — см. `magic.md`).

Длительность: `rounds` — число концов хода носителя; 0 — пока не снимут. Если задан `save_ability`/`save_dc`, носитель повторяет спасбросок в конце своего хода и при успехе снимает состояние. Одинаковые состояния не складываются: повторное наложение обновляет длительность.

## Урон

| Правило | Как в SRD 5.2 | Как у нас |
|---|---|---|
| Типы урона | 13 типов | Те же (`DamageRules.TYPES`) |
| Защиты | Иммунитет, сопротивление (½ вниз), уязвимость (×2); одинаковые не складываются; сначала сопротивление, потом уязвимость | Так же (`DamageRules.modify`) |
| Метки урона | — | У урона есть метки (`silver`, `aspen`, `iron`, `fire`…), а у защиты — список `unless`: метки, которые её обходят. Так записываются фольклорные условия: «упыря берут осина и серебро» |
| Псевдотип `physical` | «Дробящий, колющий и рубящий урон от немагических атак» | `physical` в данных = дробящий, колющий, рубящий |
